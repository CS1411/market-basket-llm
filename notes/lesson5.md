# Lesson 5 - Plant Many

32 planted itemsets: sizes 2 to 5, target supports 5%, 1%, 0.2% and 0.05%, half "natural" (items that belong together) and half "surprising" (arbitrary pairings). Chance support is checked before planting and no planted set contains another.

- Realised supports match targets to within rounding (e.g. 5.086% for one natural pair that already had some chance support).
- The four supports span a factor of 100, so recovery by support band can be measured later.

Takeaway: the planted set is a graded test, from easy (5%) to nearly invisible (0.05%).
